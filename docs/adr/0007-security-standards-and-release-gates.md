# ADR 0007 — Version-Pinned Security Standards and Mandatory Release Gates

Status: Accepted in design baseline v0.1 candidate

## Decision

FinServ Agent Gateway treats secure coding, application/API security, agentic AI security, and software supply-chain security as normative product requirements.

External standards are version-pinned in `security/standards-baseline.yaml`. The project uses explicit applicability mappings and evidence rather than blanket claims of compliance.

Implementation and release are gated by `18-SECURE-CODING-AND-SDLC.md`, `19-AGENTIC-AI-SECURITY-REQUIREMENTS.md`, `20-SECURITY-VERIFICATION-AND-RELEASE-GATES.md`, and `test/contracts/security-acceptance.yaml`.

AI- or agent-generated code is untrusted contribution and receives the same human review and security verification as human-authored code.

## Consequences

- security scanners/checks cannot silently skip;
- agent/model output can never become authority merely because it is generated by a trusted model/runtime;
- workflow integrations must separate gateway-owned controls from integration-owned controls;
- production release claims must name standard versions, scope, evidence and exceptions;
- security exceptions are explicit and time-bounded;
- core governance invariants remain non-waivable.
